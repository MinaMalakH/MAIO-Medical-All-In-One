## 🎯 Project Overview

**MAIO** (Medical Appointment Integration Online) is a complete telemedicine solution with three integrated applications:

1. **MAIO-Backend** - Node.js/Express REST API with real-time WebSocket support
2. **MAIO-front** - React patient and doctor portal
3. **maiodashboard** - Next.js admin dashboard
