## 🔄 Keeping Documentation Updated

### Update Guidelines

When making changes:

1. **Update relevant README**

   - Service README if API/feature changes
   - Main README for architectural changes
   - INSTALLATION.md for setup changes

2. **Update CONTRIBUTING.md**

   - If coding standards change
   - If process changes

3. **Update SECURITY.md**

   - If security practices change
   - If new vulnerabilities found

   - At bottom of each file
